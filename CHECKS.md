# Проверки VideoDock 1.0.1

Проверено на Windows 11 x64 с Python 3.13.7.

## Автоматические тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Все 16 тестов проходят. Они проверяют ссылки YouTube и Shorts, отклонение чужих доменов и плейлистов, таймкоды и границы интервала, доступные разрешения, выбор формата, защиту существующих файлов, обнаружение встроенного FFmpeg без системного PATH и различение сетевых ошибок.

## Интеграционные проверки

- Получение названия, длительности и разрешений 144p–2160p у открытого ролика.
- Загрузка полного видео 144p со звуком без перезаписи существующего файла.
- Точная обрезка MP4 по целым и дробным таймкодам; длительность проверена с точностью до кадра.
- Отдельное аудио MP3, M4A, WAV и Opus; видео MP4, MKV и WebM. Готовые файлы полностью декодированы FFmpeg без ошибок.
- Папки и имена файлов с кириллицей, сохранение настроек и истории.
- Отмена с остановкой рабочего процесса и дочернего FFmpeg, очистка временных файлов и восстановление кнопок.
- Работа готового `.exe` со встроенными Node.js, FFmpeg и EJS без внешних инструментов в PATH.
- Запуск обычного окна готового `.exe`, загрузка предпросмотра и отображение доступных качеств.
- Сохранение последней ошибки на диск и полного текста ошибки в подсказке.

## Проверка готового интерфейса при сборке

`build.py` автоматически запускает `VideoDock.exe --check-ui` и проверяет, что окно создаётся и кнопка скачивания доступна. Сборка считается успешной только после этой проверки.

В `.spec` исключена сторонняя `icuuc.dll`, которую упаковщик может ошибочно подобрать из PATH. Qt 6.12 использует системный ICU Windows; его подмена несовместимой библиотекой вызывает ошибку импорта QtCore.

Последняя проверка готовой версии 1.0.1 также включает загрузку MP4-фрагмента 360p со звуком и его полное декодирование встроенным FFmpeg.
