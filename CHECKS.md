# Проверки VideoDock 1.1.1

Проверено на Windows 11 x64 с Python 3.13.7.

## Автоматические тесты

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Все 30 тестов проходят. Они проверяют ссылки YouTube и Shorts, отклонение чужих доменов и плейлистов, таймкоды и границы интервала, доступные разрешения, выбор формата, защиту существующих файлов, обнаружение встроенного FFmpeg без системного PATH, различение сетевых ошибок и локализацию.

Тесты экспорта MP4 проверяют преобразование Opus в AAC с побитовым сохранением дорожки H.264, преобразование VP9 в H.264 с сохранением разрешения и дорожки AAC, сведение многоканального звука в стерео и обработку файла без звука. Уже совместимый файл остаётся побитово прежним.

Проверки локализации включают сохранение выбора языка между запусками, переключение во время загрузки без сброса формы и прогресса, перевод статусов и ошибок, историю, справку, подписи диалогов и сохранение исходных названий роликов. Также проверено совпадение параметров русских и английских шаблонов сообщений.

## Интеграционные проверки

- Получение названия, длительности и разрешений 144p–2160p у открытого ролика.
- Загрузка полного видео 144p со звуком без перезаписи существующего файла.
- Точная обрезка MP4 по целым и дробным таймкодам; длительность проверена с точностью до кадра.
- Отдельное аудио MP3, M4A, WAV и Opus; видео MP4, MKV и WebM. Готовые файлы полностью декодированы FFmpeg без ошибок.
- Папки и имена файлов с кириллицей, сохранение настроек и истории.
- Отмена с остановкой рабочего процесса и дочернего FFmpeg, очистка временных файлов и восстановление кнопок.
- Работа готового `.exe` со встроенными Node.js, FFmpeg и EJS без внешних инструментов в PATH.
- Запуск обычного окна готового `.exe`, загрузка предпросмотра и отображение доступных качеств.
- Сохранение последней ошибки на диск и полного текста ошибки в подсказке.

В версии 1.1.1 скачаны полное видео 144p и фрагмент 360p открытого ролика Big Buck Bunny. FFmpeg полностью декодировал обе дорожки и подтвердил видео H.264, звук AAC-LC стерео и сохранение выбранного разрешения.

## Проверка готового интерфейса при сборке

`build.py` автоматически запускает `VideoDock.exe --check-ui` и проверяет, что окно создаётся, кнопка скачивания доступна и переключение RU/EN работает. Сборка считается успешной только после этой проверки.

В `.spec` исключена сторонняя `icuuc.dll`, которую упаковщик может ошибочно подобрать из PATH. Qt 6.12 использует системный ICU Windows; его подмена несовместимой библиотекой вызывает ошибку импорта QtCore.

Версия 1.1.0 также проверена реальной загрузкой MP4-фрагмента со звуком: язык переключался RU → EN во время операции, рабочий процесс и параметры сохранились, итоговый статус отображался на английском. Готовый файл полностью декодирован FFmpeg. Проверка запуска собранного `.exe` подтвердила работу обоих языков.
